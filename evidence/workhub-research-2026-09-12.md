# WorkHub 一手资料核验记录（2026-09-12）

核验时间：2026-09-12 00:28 CST（UTC+08:00）

## 核验目标

确认 2026 全球智能体大赛 B 赛道所指的 WorkHub、PandaFlow 对应赛题方向、允许的接入方式和提交门槛，并判断公开信息是否足以实现平台专属适配。

## 一手来源与观察

1. [国内赛事官方报名平台](https://di.workbrain.cn/webapp/r3vh7NpFy9qm64ke/17/releases/)
   - 页面主体和内置《赛事活动标准》《B 赛道评分细则》由成都明途科技有限公司赛事页面提供。
   - B 赛道四个方向中，SP-A 是“协同调度中枢”；其范围包含意图拆解、长程规划、多 Agent 编排和状态监控等。
   - 有效 Skill 要求包含 `SKILL.md`、脚本/逻辑、测试用例和资源，可独立触发且有实质逻辑。
   - 推荐在线链接与 WorkHub 导出 ZIP 同时提交；API 文档 PDF、行业方案、蒸馏包、演示载体、封面与简介均属于提交材料。
   - 平台问答说明 Skill 主要通过可视化工作流编排，也允许自行对接 API 并由 API 调用节点连接服务。
   - 平台提供可视化智能体搭建、Skill 调试、Cx 测算和作品打包导出能力。
2. [Assumption University 东盟赛区活动页](https://www.au.edu/event/1010-digital-human-festival-ai-agent-challenge/)
   - 该校赛事页明确 Track B 使用 WorkHub 开发高级 Skills/Plugins 并连接 AI agents。
   - 该页给出海外入口 `wesomeai.com/overseas` 与支持邮箱；当前网络访问海外入口时被地区页重定向至 `workbrain.cn`。
3. [明途 OPC 智能体开发者社区](https://opc.workbrain.cn/)
   - `developer.workbrain.cn` 当前重定向至此社区；公开页面提供社区、课程和任务入口，但未公开 WorkHub manifest、API 节点字段或 ZIP 结构文档。

## 匿名浏览器核验

官方报名页可匿名查看规则、B 赛道评分细则和 131 条 Q&A。页面提供“我的作品”“报名参赛”和“前往智小途平台”入口，但当前浏览器未登录；未尝试登录、实名认证、提交、上传或修改任何平台数据。

## 21:30 登录态入口复查

在同一官方报名页重新加载并检查“我的作品 / 我的队伍 / 报名参赛”入口，按钮没有绑定导航行为。官方页面自身的运行日志明确报告身份接口归属/集成配置失效，影响是当前 JWT 壳账号无法自动补全身份，队伍恢复降级为手机号预检兜底。该警告来自主办方页面，不是 PandaFlow 服务或浏览器扩展产生。

因此本轮没有绕过身份校验、读取 Cookie/本地存储或伪造账号态，也没有继续尝试任何提交写入。当前可确认的是：**赛事公开页可读，但“我的作品”相关账号态入口受平台身份集成配置阻塞**。这不证明所有用户均受影响；恢复后仍需用参赛账号回读实际表单、鉴权和导出结构。

## 结论

- 赛事中的 WorkHub 是明途科技智能体开发平台，不是腾讯 SkillHub、海外客服产品 WorkHub.ai 或其他同名产品。
- PandaFlow 与 SP-A 高度匹配；最小改造方向是通过 WorkHub API 调用节点连接现有 PandaFlow HTTP API。
- 公开赛事材料足以确定架构方向和验收门槛，但不足以确认平台专属字段、鉴权、响应映射或导出 ZIP 格式。
- 在取得登录后界面、官方培训材料或真实导出样例前，生成所谓 WorkHub manifest 会造成伪格式风险，不能实施。
