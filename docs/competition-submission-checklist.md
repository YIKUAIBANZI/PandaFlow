# PandaFlow 赛事提交与一等奖准入清单

更新：2026-09-14

## 来源状态

2026-09-12 已在[赛事官方报名平台](https://di.workbrain.cn/webapp/r3vh7NpFy9qm64ke/17/releases/)公开页面复核《赛事活动标准》《B 赛道评分细则》和平台 Q&A；[Assumption University 东盟赛区活动页](https://www.au.edu/event/1010-digital-human-festival-ai-agent-challenge/)也确认 Track B 通过 WorkHub 开发 Skills/Plugins 并连接 AI agents。规则会更新，提交前仍须复核官方最新版本；WorkHub 登录后字段和导出格式尚无公开一手文档。

## 当前结论

- **本地工程基线：通过。** 6 个 Skill 均有独立入口、业务逻辑、HTTP 契约和自动化测试；总控包含多步流程、异常分支、领域规则和真实 Open-Meteo API。
- **赛题方向：已确认 SP-A。** PandaFlow 覆盖意图拆解、长程规划、多 Skill 编排和状态/证据记录；不声称覆盖博弈推演、群体涌现或协同压测。
- **Cx 复杂度基线：本地证据满足 4/5。** 前四项均有代码与测试；第五项“与 WorkHub/智能体/空间形成非平凡业务闭环”尚无平台证据。是否被评审认可仍取决于官方口径与现场验收。
- **一等奖准入：未完成。** 公网 Web Demo 不等于平台认可的 Live Demo；能力超市尚未上架，终版蒸馏包尚未形成，专家评分未知。
- **当前不可锁定提交。** Q&A 表述为提交后即锁定，除非因可补救的技术问题被驳回。在所有链接、平台状态、材料格式和隐私检查完成前，不执行最终提交。

## 资格与合规待用户确认

- 参赛者是否只加入 1 支队伍、1 个赛道，且不存在同身份证跨赛区/赛道重复报名。
- 全体成员是否完成实名认证；个人开发者是否已经准备 OPC 开发者认证截图。
- 队伍名称是否满足 2–20 字、不含学校名称、指导老师姓名、敏感词或广告词。
- 最终使用的字体、图标、截图、音乐、视频和第三方代码是否逐项记录来源及许可证。
- 最终提交账号、团队信息和平台页面是否均可正常访问；这些属于外部账号状态，代码仓库无法代替确认。

## 提交顺序

1. 依据 `workhub-integration-runbook.md` 在登录后采集真实字段和最小导出样例；先不要批量创建 6 个 Skill。
2. 使用已部署的 `https://pandeflow.yikuaibanz.cn`，在 WorkHub 内先完成 `visitor-policy-check` 正常/异常回传烟测，再扩展到 6 Skill 闭环。
3. 完成能力超市上架和平台 Live Demo，回读状态并保留证据。
4. 更新公开白名单快照，完成来源/许可证/隐私扫描。
5. 以真实平台界面按 `competition-presentation-kit.md` 录制 MP4；完成终版方案书、蒸馏包和原创封面，并把 API PDF 补齐平台鉴权配置及实测字段后冻结。
6. 在未锁定状态下逐项预览链接、权限、格式、时长和内容。
7. 仅在所有硬门槛均有证据且用户明确确认最终版本后提交；提交后立即保存状态页和时间戳截图。

## 一票否决防线

- 不复制或跨项目复用无授权素材；所有开源代码和第三方素材写明来源与许可。
- 不伪造 Skill、专家访谈、行业材料、平台状态、客户合作、实时客流或动物状态。
- 不包含恶意代码、数据窃取或权限绕过；不收集真实身份证号、手机号或健康隐私。
- 不刷票，不提供或使用规避防刷机制的方案。
- 任何演示合成数据继续标注 `demo_data=true`；真实天气也不冒充园区运营或动物健康数据。
